# Quick Start

1. `pip install -r requirements.txt`
2. Edit app.py line 14 with MongoDB URI
3. `python app.py`
4. Open http://localhost:5000
5. Register & test!

## Test Checklist
✅ Register owner & supplier
✅ Supplier requests product
✅ Owner approves (status changes!)
✅ Owner sells product  
✅ Low stock alert appears
✅ Reorder generated
✅ Supplier fulfills
